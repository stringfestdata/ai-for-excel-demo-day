# AI for Excel Demo Day

A 45-minute watch-along with George Mount: ask a business question, inspect the answer, reshape the data with Power Query, and verify the result.

## Session files

- `wholesale-customers.xlsx`: starting dataset (unchanged).
- `Data Dictionary.md`: field definitions, category codes, and reference totals.
- `AI-for-Excel-Demo-Day.pptx`: slides and presenter notes.
- `Extras/AI-for-Excel-Demo-Day-Takeaway.pdf`: one-page takeaway.
- `Extras/The-Art-and-Science-of-AI-Prompting.pdf`: Microsoft's original prompting reference.
- `instructor/`: presenter walkthrough.

Watching is welcome; no software purchase or live workbook work is needed to attend. To try the demo later, feature availability depends on your Excel version and account.
